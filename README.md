# E-commerce

A e-commerce system built with Laravel.

## Features

- Multi Authentication (Admin, Vendor, User)
- RBAC using Spatie Laravel Permission
- KYC Verification
- Stripe Payment Gateway
- Shopping Cart & Checkout
- Coupon Management
- Reviews & Ratings
- Newsletter & Contact System

## Technologies

- Laravel
- PHP
- MySQL
- JavaScript
- Bootstrap
- Stripe
- Spatie Laravel Permission

## Installation

```bash
git clone https://github.com/omar-mohamedomar/boutique.git

cd news

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```
